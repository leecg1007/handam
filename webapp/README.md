# 한담 웹앱

`prototype-claude.html`을 웹앱 폴더 구조로 옮긴 버전입니다.

## 실행

브라우저에서 `index.html`을 열면 바로 실행됩니다. 프로젝트 루트 또는 이 폴더에서 아래 명령을 실행하세요.

```powershell
npm start
```

그 다음 `http://localhost:4173`으로 접속하면 됩니다.

## 구성

- `index.html`: 화면 구조
- `styles.css`: 원본 스타일 전체
- `app.js`: 원본 상호작용 로직 전체
- `manifest.webmanifest`: 홈 화면 설치용 기본 웹앱 매니페스트
- `server.cjs`: 로컬 확인용 서버
